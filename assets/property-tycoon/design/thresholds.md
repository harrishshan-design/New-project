# Runtime Thresholds

- Target frame rate: 60 fps desktop and mobile.
- Maximum device pixel ratio: 1.5.
- Fixed simulation step: 16.667 ms.
- Main-thread frame budget: 12 ms.
- Canvas draw calls per frame: under 80.
- DOM property cards visible at once: 14 or fewer.
- First meaningful action: within two taps or clicks after launch.
- Autosave payload: under 100 KB in local storage.
- Touch target minimum: 44 by 44 CSS pixels.
- Smallest supported viewport: 360 by 640 CSS pixels.
- Text contrast: WCAG AA for all decision-critical labels.
- Market event randomness: seeded and drawn without replacement before reshuffling.
- Save version: 1; incompatible saves must fail closed to a fresh campaign.
